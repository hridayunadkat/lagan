# LAGAN

A mobile-first self-improvement PWA that turns daily habits into character
progress across Physical, Social, Discipline, Mental, Finance, and Ambition.

## Run locally

```bash
npm install
npm run dev
```

## Verify

```bash
npm test
npm run lint
npm run build
```

LAGAN works locally without an account and includes a populated demo mode.
Supabase account setup instructions are in `SUPABASE_SETUP.md`.
